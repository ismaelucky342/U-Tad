### **Course Overview**

This course teaches the algorithms used to automatically build intelligent systems from domain-specific datasets, with the goal of extracting and modeling the knowledge contained in them for later use in intelligent decision-support systems. The models covered are the classic supervised and unsupervised learning algorithms, focusing on their mathematical development and their implementation in the R programming language (and Python).

### **Learning Outcomes**

By the end of this course, students will be able to:

- Know and apply the different supervised, semi-supervised, and unsupervised learning techniques.
- Understand and apply deep learning techniques.
- Recover information through web scraping techniques or standardized APIs.
- Understand and apply natural language analysis techniques.
- Develop data analysis and modeling workflows over real datasets.
- Understand the mathematical foundations behind the main learning algorithms.

### **Course Units**

1. **Unit 1: Introduction to Machine Learning**
    - What machine learning is, the types of learning, model creation, and performance evaluation.
2. **Unit 2: Data Analysis with R (and Python)**
    - Introduction to the R environment and Python libraries, descriptive statistics, multivariate analysis, and linear algebra for ML.
3. **Unit 3: Prediction Models (Supervised Learning)**
    - Linear and multiple regression, logistic regression, SVM, decision trees, and K-NN, including a real project with exploratory analysis.
4. **Unit 4: Description Models (Unsupervised Learning)**
    - Hierarchical and K-means clustering, PCA, and association rules.
