# Ejercicios · U1 Introducción al Aprendizaje Automático

Requisitos: Python 3.10+ con `numpy`, `pandas`, `scikit-learn` (`pip install numpy pandas scikit-learn`).
Cada script es autónomo, usa semillas fijas y no descarga nada. Ejecuta con `python ejXX_*.py`.
Cada fichero trae el **enunciado** en la cabecera y la **solución comentada** al final.

| # | Fichero | Dif. | Tema (apartado del temario) |
|---|---|---|---|
| 1 | `ej01_tipos_y_dataset.py` | ⭐ | Anatomía del dataset; supervisado vs no supervisado (§7) |
| 2 | `ej02_descenso_gradiente.py` | ⭐⭐ | Modelo + pérdida + optimizador; tasa de aprendizaje; outliers (§5.4) |
| 3 | `ej03_sobreajuste.py` | ⭐⭐ | Under/overfitting, la «U» del test, efecto de más datos (§10) |
| 4 | `ej04_metricas_clasificacion.py` | ⭐⭐ | Métricas, desbalance, umbral, coste de errores (§11) |
| 5 | `ej05_pipeline_validacion_cruzada.py` | ⭐⭐⭐ | Flujo completo: preprocesado, CV, test único, data leakage (§9-10) |

**Cómo trabajarlos:** lee el enunciado, intenta resolverlo tú sin mirar la parte de código, ejecuta y compara con la sección «SOLUCIÓN / qué observar».
