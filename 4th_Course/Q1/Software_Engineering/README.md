### **Course Overview**

The *Software Engineering* course is where students learn to plan and develop software projects, shifting from conceiving the task from the programmer's point of view to contemplating it from the perspective of the technical project manager. Specifically, students learn to plan and manage software development projects using different methodologies, to build work teams to carry out software development projects, and to describe software architectures and designs using graphical languages.

### **Learning Outcomes**

By the end of this course, students will be able to:

- Know formal specification languages.
- Identify and use design patterns to solve problems.
- Apply refactoring techniques.
- Understand the software life cycle.
- Understand and apply waterfall methodologies in development.
- Understand and apply Scrum in development.

### **Course Units**

1. **Unit 1: Introduction to Software Engineering**
    - Introduction to software engineering, risks, and an introduction to requirements.
2. **Unit 2: Requirements Management and Software Design**
    - Requirements management, inception and design thinking, UML diagrams, vision, epics and user stories, prioritization, and estimation.
3. **Unit 3: Software Development Models and Methodologies**
    - Software development models and methodologies, the unified process, SCRUM, KANBAN, and XP.
