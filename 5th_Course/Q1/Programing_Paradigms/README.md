### **Course Overview**

This course allows students to understand the different programming paradigms that currently exist, showing the alternatives available when making decisions for software development. Throughout the degree, the main programming paradigms of recent decades have been covered: structured programming, procedural programming, object-oriented programming, and concurrent programming. In this course we focus on two new approaches: functional programming and reactive programming.

The approach of the course is therefore mainly practical, based on the exhaustive development of examples on the most common development environment at present, which is Python and its specialized libraries.

### **Learning Outcomes**

By the end of this course, students will be able to:

- Understand the different paradigms behind programming languages.
- Apply the functional programming paradigm using Python.
- Apply the reactive programming paradigm using Python.
- Choose the most appropriate paradigm for a given software development problem.
- Develop practical examples and exercises in specialized Python libraries.
